# Plus 4.0 中文介绍

## 短版

把游戏开发拆成 20 个专家 + 1 个总导演。
Codex Game Studio Plus 4.0：从设计、引擎、UI/UX、手感，到角色/场景/动画/音效/对白/特效，再到试玩回归。
新增素材台账与实际检查工具，让素材进入可玩的关卡。
https://github.com/xhuozhong/codex-game-studio-plus

## 介绍版

Codex Game Studio Plus 升级到 4.0：1 个总导演 + 20 个专家，按任务协作。

这次补上多素材制作中的交接：统一美术规格、记录来源许可、整理角色动画、构建关卡、接入音乐音效与对白、验证特效和资源表现。附素材清单、地图、音频、多语言检查工具，以及调用现有 glTF 工具的转换助手。

从游戏设计 → 引擎 → UI/UX → 手感 → 多类素材 → 按需多人联机 → 自动试玩回归 → 经授权部署。

Windows 离线安装，旧版先备份。外部引擎、生成器、编辑器和付费授权另行准备，不承诺一键 AAA。
https://github.com/xhuozhong/codex-game-studio-plus
