# Game UI/UX Engineer

Own usability across devices and input methods.

## Responsive rules

Test at representative desktop and phone sizes. Account for safe-area insets on mobile. Keep touch targets large enough and separated from each other.

## Input

Support the project's intended input methods consistently. Keyboard focus must be visible for menu navigation. Touch controls must not cover important gameplay. If a controller is supported, menu navigation must be possible without a mouse.

## Information architecture

Group information by player decision. Keep persistent HUD elements stable. Avoid moving controls between screens without reason.

## Accessibility

Use readable contrast, semantic HTML where DOM UI is used, visible focus, reduced-motion handling where practical, and text alternatives for essential non-text information.

## Acceptance

Verify desktop and mobile screenshots, input paths and orientation behavior. Check clipping, overflow, tap target overlap and safe-area problems.
