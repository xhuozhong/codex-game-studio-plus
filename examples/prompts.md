# 可复制的调用示例

## 总导演接管

```text
$game-studio-director
读取当前游戏项目，确认引擎版本和真实启动命令。
提出一个可以试玩验收的小功能，选一位主专家与必要的辅助专家，完成实现、试玩和回归。
保留既有存档与工作功能；未运行的测试必须单独说明。
```

## Phaser 场景修复

```text
$phaser-specialist
检查当前 Phaser 版本。修复重开关卡后重复监听和重复计分，不升级引擎。
提供实际重开三次的验证结果，并检查资源加载失败时的反馈。
```

## 数值验证

```text
$gameplay-balance-validator
先确认分数、击杀奖励与技能冷却的设计约束，为这些事件加入可检查的遥测。
使用固定种子和同样输入策略比较修改前后；区分正确性、表现差异和样本不足。
这个项目是放置游戏，请勿自动采用反挂机规则。
```

## 精灵动画交付

```text
$sprite-animation-pipeline
检查我提供的精灵表网格，统一每帧脚底锚点，导出透明帧、图集与动画预览。
不要覆盖原图；先展示接触表，再把动画接入游戏检查抖动、帧序和透明边缘。
```

## 网页 3D 资源检查

```text
$web-3d-asset-optimizer
检查项目的 GLB 资源，记录体积、网格、材质和纹理预算。
先确认可用工具，再做有必要的优化；保留原文件，并在实际网页里比较视觉与加载表现。
```

## UI 与手感

```text
$game-studio-director
改善战斗 HUD 与攻击反馈，保留现有引擎与玩法。
验证键鼠与触屏操作、暂停/重新开始、关键状态显示，以及修改后的截图和控制台。
```

## 明确要求多人联机

```text
$game-studio-director
为当前游戏加入两人房间模式。先定义服务器权威状态、连接/离开/重连边界与验收标准。
再交付最小联机切片；不要同时引入账号、付费或排行榜。
```
