# 多素材接入验证样例

这是独立编写的几何美术验收样例，不是高品质商业游戏模板，也不证明外部生成器或引擎已经接通。无第三方运行依赖：SVG 精灵/图块、Tiled 风格有限地图 JSON、本地化表、Canvas 动画/特效、Web Audio 与本地存档。

在本目录运行 `python build_audio.py` 一次，生成原声音效 WAV；再次运行会拒绝覆盖。然后从本目录启动 `python -m http.server 8765 --bind 127.0.0.1`，访问 `http://127.0.0.1:8765/`。首次进入点击“开始 / 启用声音”。使用方向键/WASD 或方向按钮移动，空格或攻击按钮攻击。接受任务，靠近敌人攻击两次，再到右侧出口。可切换中英文、保存读取及重置。浏览器自动播放策略仍要求真实交互。

`manifest.json` 只列出随源码交付的静态素材，全部标记 processed，未携带运行验收证据；故 `--release` 应失败。生成的 WAV 不在静态清单中，使用 asset_manifest.py record 创建记录后人工核对并补入项目清单。不要因示例“能运行”而自动给不同项目盖章。

源码、SVG 与 build_audio.py 生成的原创声音适用本目录 LICENSE；不含外部商业资源。生产工具并未绑定此样例的房间大小、素材数量或美术风格。
